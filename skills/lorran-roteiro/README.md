# lorran-roteiro

Roteiro pronto pra gravar (Reels, TikTok, Shorts, YouTube) para o @lorrandev: classifica o post
nas 4 camadas e nos 4 momentos da marca, gera 5 hooks, desenha a curva de retenção com reengates
e laços abertos, define o gatilho de compartilhamento, o CTA único e a direção visual, e dá nota
ao próprio roteiro antes de entregar.

Lê `claude/estrategia-conteudo-2026-11.md` no projeto "Lorran Dev" do Claude. Feita para uso
pessoal; para outro criador, troque o posicionamento, os números e os exemplos.
